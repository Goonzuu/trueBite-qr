# 📦 Repositorio Backend

## ✅ Configuración

El backend está conectado al mismo repositorio que el frontend:
- **Repositorio:** https://github.com/Goonzuu/trueBite-qr
- **Branch:** `backend`

## 🔄 Estructura del Repositorio

```
trueBite-qr/
├── app/              # Frontend (Next.js) - branch: etapa-1-setup / master
├── lib/              # Frontend (Next.js)
├── package.json      # Frontend
└── ...
```

El backend está en un branch separado (`backend`) para mantener la separación mientras están en el mismo repositorio.

## 📋 Comandos

### Backend (branch: backend)
```bash
cd trueBite-qr-back
git push origin backend
```

### Frontend (branch: etapa-1-setup)
```bash
cd trueBite-qr
git push origin etapa-1-setup
```
